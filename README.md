# 커리어 나침반 - 공개 웹페이지

학생이 이력서와 자기소개서를 붙여 넣어 지원 직무 기준의 피드백을 받는 단일 페이지 웹사이트입니다. 기본 지원서 점검과 채용공고 맞춤 작성 모드를 제공하며, 입력한 내용은 브라우저 안에서만 처리하고 저장하거나 전송하지 않습니다.

## 바로 실행

`index.html` 파일을 브라우저에서 열면 됩니다.

## 공개 배포

이 폴더의 파일 전체를 GitHub Pages, Cloudflare Pages 또는 Netlify 같은 정적 웹 호스팅에 업로드하면 누구나 링크로 접속할 수 있습니다.

## 현재 기능

- 기본 지원서 점검 및 채용공고 맞춤 작성 모드
- 지원 직무·경력 수준·채용공고·이력서·자기소개서·경험 근거 입력
- 공고 핵심역량, 경험 근거, 보완 우선순위, 수정 문장 공식, 상담 질문 제안
- 예시 데이터 기반 시연 모드

## 운영 전 유의사항

- 주민등록번호, 연락처, 주소, 학교명 등 개인정보는 입력하지 않도록 안내합니다.
- 현재 버전은 개인정보 보호를 위해 브라우저 내 규칙 기반으로 분석합니다. 생성형 AI로 사실에 근거한 문장 초안을 만들려면 별도 서버리스 API를 연결하세요.
- 실제 생성형 AI 첨삭을 추가하려면 API 키를 웹페이지에 넣지 말고, 별도 서버리스 API를 통해 연결해야 합니다. 이때 개인정보 처리방침, 사용량 제한, 상담사 검토 절차를 함께 마련하세요.

# 커리어 나침반 - 이력서·자기소개서 맞춤형 첨삭 자동화

학생이 이력서와 자기소개서를 붙여 넣거나 파일로 첨부하면, **①서류분석 → ②첨삭의견 → ③수정안 작성 → ④맞춤형 피드백** 4단계로 결과를 자동 생성하는 단일 페이지 웹사이트입니다. 입력한 내용은 브라우저 안에서만 처리하고 저장하거나 전송하지 않습니다.

`index.html` 한 파일에 CSS/JS가 모두 포함된 단일 파일 구조이며, `app.js`·`style.css`는 이전 버전에서 쓰이던 파일로 현재 `index.html`은 이를 불러오지 않습니다(참고용으로만 보관, 삭제해도 무방).

## 바로 실행

`index.html` 파일을 브라우저에서 열면 됩니다.

## 공개 배포

`index.html`과 `logo.png`를 GitHub Pages, Cloudflare Pages 또는 Netlify 같은 정적 웹 호스팅에 업로드하면 누구나 링크로 접속할 수 있습니다.

## 4단계 자동화 구현 내용

1. **서류분석 (4항목 이상)**: 입력 문장을 문장 단위로 분리한 뒤 키워드 기반으로 `경력·주요 경험 / 핵심 역량 / 지원동기 / 자기PR·강점` 4개 항목으로 자동 분류하고, 항목별 근거 문장과 보완 코멘트를 제시합니다.
2. **첨삭의견**: `문장 표현`(추상적 다짐 표현, 장문 여부, 정량 표현 유무) · `구성`(포부 문장 유무, 분량, 행동 동사 사용) · `직무적합성`(직무 표준 키워드 매칭률, 채용공고 키워드 매칭률)을 각각 진단합니다.
3. **수정안 작성**: 실제로 입력한 문장 중 추상적 표현(예: "최선을 다하겠습니다")을 탐지해 보유 역량·정량 성과 중심 문장으로 재작성한 Before & After를 제공합니다. 개선 대상 문장이 없으면 직무 표준 패턴 기반 참고 예시를 보여줍니다.
4. **맞춤형 피드백**: 직무적합도 점수(0~100), 개인별 강점/보완 우선순위, 예상 면접 질문을 종합 총평과 함께 제공합니다.

## 개인정보 보호 (수정 이력)

- **수정안(Before & After)은 이력서가 아닌 자기소개서 문장만 사용**합니다. 이력서에는 이름·생년월일 등 개인식별정보가 남아있을 수 있어, 첨삭 예문으로 노출되지 않도록 소스를 분리했습니다.
- 생년월일 표기(예: 1998.03.15, 980315), "이름/성명 : 홍길동" 형태의 값도 자동으로 정제한 뒤 분석합니다. 다만 규칙 기반 정제이므로 완벽하지 않을 수 있어, 업로드 전 개인정보를 직접 한 번 더 확인해 주시는 것을 권장합니다.

## 링커리어 등 합격 자소서 커뮤니티 반영 방식

- 이 웹페이지는 서버 없이 브라우저에서만 동작하는 정적 페이지이며, 링커리어(linkareer.com)는 자사 콘텐츠의 무단 크롤링·상업적 이용을 이용약관으로 금지하고 있어 실제 합격 자소서 원문을 실시간으로 가져오거나 그대로 인용하지 않습니다.
- 대신 링커리어 등 다수의 취업 커뮤니티가 공통으로 안내하는 **STAR(상황-역할-행동-성과) 구조**와 **두괄식(결론 먼저 제시) 작성법**을 일반화하여 수정안 생성 로직과 첨삭의견(구성 항목)에 반영했습니다.
- 결과 화면의 "수정안 작성" 카드에는 직무 키워드로 검색되는 `링커리어 자소서 만능검색기` 링크를 제공하여, 사용자가 직접 최신 합격 자소서 사례를 열람할 수 있도록 안내합니다.

## 부가 기능

- 기본 지원서 점검 모드 / 채용공고 맞춤 분석 모드 선택 (공고 텍스트·PDF 입력 시 공고 키워드 매칭 반영)
- 이력서·자기소개서·채용공고 PDF/TXT 업로드 또는 직접 텍스트 입력
- 개인정보(이메일, 전화번호, 주소 등) 자동 정제 후 분석
- 예시 데이터 자동 입력으로 즉시 시연 가능
- 결과 화면을 PDF로 다운로드(인쇄) 가능

## 운영 전 유의사항

- 주민등록번호, 연락처, 주소, 학교명 등 개인정보는 입력하지 않도록 안내합니다.
- 현재 버전은 개인정보 보호를 위해 브라우저 내 규칙 기반으로 분석합니다. 생성형 AI로 사실에 근거한 문장 초안을 만들려면 별도 서버리스 API를 연결하세요.
- 실제 생성형 AI 첨삭을 추가하려면 API 키를 웹페이지에 넣지 말고, 별도 서버리스 API를 통해 연결해야 합니다. 이때 개인정보 처리방침, 사용량 제한, 상담사 검토 절차를 함께 마련하세요.
